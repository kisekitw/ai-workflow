Copilot 飄移警戒訊號（出現即停手）

✗推薦你找不到的 NuGet 套件（幻覺率約 15%，務必手動核查 nuget.org）
✗一次 refactor 動到 10+ 個不相關檔案（Copilot 在擴大範圍迴避複雜性）
✗Approval test 出現非預期 snapshot diff（行為已改變，立即 revert）
✗Session 中途自動 revert 剛改好的程式碼（已知 Agent Mode bug，早 commit 早省心）
✗net472 檔案出現 C# 10+ 語法（init、record、switch expression）
✗對同一問題前後給出矛盾答案（Context 已失控，開新 session）

完整時間軸

階段 人力配置 時長 關鍵里程碑
Phase 0 · 考古 3–5人 Guild 4–6 wks 模組地圖、Analyzer baseline CSV、No-go 清單

Phase 5 · 規模化 Guild → 全員 Week 8+ 持續 15 人全員掌握 4 個核心 slash commands；AI_WORKFLOW.md 發布
